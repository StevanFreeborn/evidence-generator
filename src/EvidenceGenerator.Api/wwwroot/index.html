Service Overview

The Evidence Generator service accepts requests for automated evidence collection, creates the target file in memory, creates an Onspring record, and uploads the generated artifact as an attachment to that record.

Requests submitted to POST /generate are validated and placed onto a background processing queue. The service immediately returns 202 Accepted with a job identifier while generation and Onspring upload run in the background.

Generate with an LLM

If you are using an LLM (such as ChatGPT, Claude, or Copilot) to convert logs, scan results, or audit artifacts into a valid JSON request payload, copy this prompt context and paste it into your LLM along with your source data or requirements. 

You are an assistant generating valid JSON request bodies for the Evidence Generator API.

Endpoint: POST /generate
Header: Content-Type: application/json
Header: X-Onspring-ApiKey: <YOUR_API_KEY>

The request must be a valid JSON object matching this schema:

Base Properties (Required for all types):
- "fileType": string (Required) - Exactly one of: "txt", "html", "csv", "xlsx", "docx", "pptx", "pdf", "json", "jsonl"
- "appId": integer (Required) - Target Onspring Application ID (e.g. 1050)
- "attachmentFieldId": integer (Required) - Target Attachment Field ID (e.g. 5012)
- "fileName": string (Required) - The file name (e.g. "evidence_output.txt")
- "notes": string (Optional) - Description or notes for the uploaded file record
- "recordFields": object (Optional) - Dictionary of Onspring field ID (as string or int) to field value (string, number, array of strings/numbers)

Format-Specific Properties (Add based on "fileType"):

1. When "fileType": "txt"
- "text": string (Required) - Plain text content

2. When "fileType": "html"
- "title": string (Required) - Document title
- "markdownOrHtmlBody": string (Required) - Body content in Markdown or HTML

3. When "fileType": "csv"
- "headers": array of strings (Required) - Column header names
- "rows": array of arrays of strings (Required) - Table rows matching headers

4. When "fileType": "xlsx"
- "sheets": array of objects (Required), each with:
  - "sheetName": string (Required) - Sheet name
  - "columns": array of strings (Required) - Column header names
  - "rows": array of arrays of strings (Required) - Matrix of row cells

5. When "fileType": "docx"
- "title": string (Required) - Document title
- "sections": array of objects (Required), each with:
  - "heading": string (Optional) - Section heading
  - "paragraphText": string (Required) - Section body text
- "table": object (Optional) with:
  - "headers": array of strings (Required) - Table column headers
  - "rows": array of arrays of strings (Required) - Table rows

6. When "fileType": "pptx"
- "slides": array of objects (Required), each with:
  - "title": string (Required) - Slide title
  - "bulletPoints": array of strings (Required) - Bulleted list of text items

7. When "fileType": "pdf"
- "title": string (Required) - Document title
- "sections": array of objects (Required), each with:
  - "heading": string (Optional) - Section heading
  - "body": string (Required) - Section body text

8. When "fileType": "json"
- "data": object or array (Optional) - Arbitrary structured JSON data (serialized formatted and indented)
- "json": string (Optional) - Raw JSON string (one of "data" or "json" is required)

9. When "fileType": "jsonl"
- "lines": array of objects (Optional) - Array of records serialized as newline-delimited JSON
- "text": string (Optional) - Raw multiline JSONL string (one of "lines" or "text" is required)

Task Instructions:
- Output ONLY a single, valid, raw JSON object without markdown fences or extraneous commentary.
- Ensure all required fields are present and properly typed.
- Fit the evidence content logically into the chosen format.

Authentication

Requests to POST /generate require an Onspring API key passed in the request header:

X-Onspring-ApiKey: <YOUR_ONSPRING_API_KEY>

Requests without a valid API key return 401 Unauthorized.

POST /generate

Header: Content-Type: application/json

Success Response: 202 Accepted

{
  "jobId": "3fa85f64-5717-4562-b3fc-2c963f66afa6",
  "status": "Queued"
}

Base Request Parameters

All payloads sent to POST /generate accept these base fields:

Field Type Required Description
fileType string Yes Format discriminator: txt, html, csv, xlsx, docx, pptx, pdf, json, jsonl.
appId integer Yes Target Onspring Application ID where the record will be created.
attachmentFieldId integer Yes Target Attachment Field ID where the file will be attached.
fileName string Yes File name (e.g. audit.txt). File extension is normalized automatically if omitted.
notes string No Optional notes or description attached to the file record.
recordFields object No Key-value map of integer Onspring Field IDs to values to populate on the created record.

Supported Formats & Request Examples

1. Plain Text (fileType: txt)

Used for server configurations, command-line outputs, and cryptographic checksums.

{
  "fileType": "txt",
  "appId": 1050,
  "attachmentFieldId": 5012,
  "fileName": "sshd_config_bastion_prod_01.txt",
  "notes": "Automated snapshot of /etc/ssh/sshd_config from prod-bastion-us-east-1a",
  "recordFields": {
    "1201": "CC6.1 - Access Control Configuration",
    "1202": "Automated Compliance Collector (Cron)",
    "1203": "PASS"
  },
  "text": "=== Host: prod-bastion-us-east-1a ===\nTimestamp: 2026-10-29T14:00:00Z\nSha256: e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855\n\n# OpenSSH Server Configuration Snapshot\nPort 22\nProtocol 2\nPermitRootLogin no\nPasswordAuthentication no\nPubkeyAuthentication yes\nAuthorizedKeysFile .ssh/authorized_keys\nKexAlgorithms curve25519-sha256@libssh.org,diffie-hellman-group-exchange-sha256\nCiphers chacha20-poly1305@openssh.com,aes256-gcm@openssh.com,aes128-gcm@openssh.com\nMACs hmac-sha2-512-etm@openssh.com,hmac-sha2-256-etm@openssh.com\nClientAliveInterval 300\nClientAliveCountMax 2\nMaxAuthTries 3\nBanner /etc/issue.net\n\n# Verification Check:\n# [PASS] PermitRootLogin is 'no'\n# [PASS] PasswordAuthentication is 'no'\n# [PASS] Deprecated ciphers (3des, arcfour) are not present\n"

HTTP Status Codes

Status Code Meaning Details
200 OK Documentation Served for any navigation request outside of POST /generate.
202 Accepted Queued Request accepted and queued for background generation & Onspring upload. Returns jobId.
400 Bad Request Validation Error Invalid JSON or missing/unsupported fields. Returns RFC 7807 ProblemDetails.
401 Unauthorized Unauthorized Missing or empty X-Onspring-ApiKey header.
500 Internal Error Server Error Unexpected error. Returns RFC 7807 ProblemDetails.
